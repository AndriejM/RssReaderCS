## Отзывает: Suspense/ErrorBoundary — не мёртвый код

`useRssContentStoreAsync = hook(useRssContentStore)` — это как раз штатный паттерн leo-query: `hook()` возвращает подписку, которая **suspend-ится** (бросает promise), пока запрос по текущим зависимостям не разрешён. То есть:

- `<Suspense fallback>` действительно покажет `"Loading..."` при загрузке и при refetch после смены `rssId` (зависимость `(s) => [s.rssId]`);
- ошибки fetch'а (`getRssById`) пробрасываются в рендер и ловятся `<ErrorBoundary>` — тоже штатный механизм.

Заодно отзывается и часть пункта про «stale data»: при смене `rssId` компонент подвешивается на время refetch, так что старые данные нового id не отрисовываются. Единственное узкое место остаётся: **первый** рендер до срабатывания `useEffect` происходит при `rss === null`, и на один кадр покажется `"No description available"` вместо лоадера — косметика, но её можно убрать (см. ниже).

## Что из ревью остаётся в силе

**1. Синхронизация пропса в store через `useEffect`** — всё ещё главный аргумент. Теперь он менее критичен (Suspense прикрывает загрузку), но паттерн «adjusting state in effect» никуда не делся: лишний цикл рендеров + эффект после paint. Варианты:
- держать выбранный `rssId` в URL (`react-router-dom`) и синхронно читать его в store/запросе;
- или родитель сам обновляет store до/вместо рендера ребёнка (например, через контекст/роутер), а не через эффект внутри компонента.

**2. `ErrorBoundary` без сброса — реальная проблема.** В React 19 есть `resetErrorBoundary`, но если он не используется: запрос для одного RSS упал → boundary вошёл в error-state → пользователь переключил на другой RSS → всё равно остаётся `"Error loading ..."`, потому что boundary не пересоздаётся. Лечится просто:

```
<ErrorBoundary fallback={<div>Error loading ...</div>} key={props.rssId}>
```


(или `resetErrorBoundary` в React 19) — так ошибка одного id не «зависает» на весь список.

**3. DOMPurify по умолчанию для чужого RSS-HTML** — всё ещё актуально: `<img src>`/`<a href>` из описания = трекинг/утечка IP, inline `style` = CSS-инъекция. Стоит передать конфиг (`ALLOWED_TAGS` / запрет сетевых атрибутов) или хотя бы осознанно зафиксировать текущее поведение.

**4. Мелочи без изменений:** hardcoded-строки, текст ссылки — «сырой» URL (лучше `rss.title`), сузить зависимость `useMemo` до `rss?.itemPayload?.description`, единый стиль кавычек с остальным кодом.
